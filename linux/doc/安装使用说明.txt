桌面挂件合集包
================

版本：2.9.78

一、安装
1. 双击本文件，使用深度安装器打开。
2. 在安装器中点击“安装”，等待安装完成。
3. 如果双击安装失败，可在终端执行：
   sudo apt install ./桌面挂件合集包_2.9.75_all.deb

二、内容
本包是桌面挂件和任务栏工具合集，包含桌面日历、相框、监控、视频、音乐、便签、收音机、RSS、计时器、天气、记账、边缘滚轮控制、热键启动器、显示器输入切换、任务栏信息条、鼠标拖尾、截图 OCR、复制工具条和系统清理工具。

三、本次更新（RSS）
1. 修复底部状态栏“失败来源”名单被截断、末尾出现省略号的问题：状态栏可用
   宽度原来写死 260 像素，有两个以上源刷新失败时名单就放不下，现在改为
   按“刷新”按钮位置动态计算宽度。
2. 名单过长时依次把字号从 13 缩到 12、11 像素，仍放不下就显示“失败 N 项”，
   再不行只保留刷新时间，任何窗口大小下都能完整显示，不会出现“…”。
3. 自动铺满屏幕时，窗口底边与底部任务栏（状态栏）留出 1 厘米间距，不再紧贴
   任务栏；升级后会自动重新铺满一次，之后仍保留用户手动调整的尺寸和位置。

四、本次更新（监控）
1. 硬盘区只显示本系统盘（/）和所有外接硬盘/U 盘（USB），不再显示内置硬盘上
   的其它分区（包括其它 Windows 分区和其它 Linux 分区）。
2. 外接硬盘/U 盘插入后自动出现，无需重启挂件。

五、收音机说明
桌面收音机优先使用已安装“电台”软件的播放源：
/usr/share/dtbox/radioData.json
如果系统中没有安装“电台”软件，则自动使用本包内置的备用播放源：
/usr/local/lib/desktop-radio/radioData.json
选台弹窗为黑底白字，宽度较窄，并会置顶显示。网络电台需要联网才能播放。

六、本次更新（收音机）
1. 开机、注销后重新登录、重启后都不自动播放，只有点击面板上的“播放”
   或在选台弹窗里挑选电台才开始出声；没播放时不会在后台空跑 mpv。
2. 播放看门狗：用户开始播放后，网络抖动、音频设备未就绪导致 mpv 自己
   暂停时，挂件会自动重新连接（重试间隔 4～30 秒）。
3. 面板标题显示电台名称，不再显示 64.m3u8 这类文件名。
4. 选台弹窗：鼠标点击桌面空白处（或按 Esc）自动收回隐藏。
5. 修复“开机自启”勾选项永远显示为未勾选，以及自启时没走守护包装脚本的问题。
6. 日志改写到 ~/.config/desktop-radio/radio.log，便于排查。

七、本次更新（记账）
1. 修复“本月支出/本月收入/本月结余”标签与数值之间几乎没有行间距的问题：
   改为按文字实际占高自动留出行距（默认字号下约 18px），汇总区边框高度
   64→76px。
2. 修复“本月支出分类”标题与第一行分类（如购物）之间没有间距的问题：默认
   字号下行距 14px，分类区高度 92→100px，并随字号自适应加高。
3. 升级后窗口比原来略高属正常现象（汇总区和分类区都加了高度）；窗口高度
   仍随记录条数自动调整，可在右键菜单里取消“高度随条目自动增减”。
4. 紧急修复（2.9.67）：2.9.66 打包时启动脚本丢失了可执行位，升级后重启
   系统会导致所有挂件都无法启动；本版已逐文件恢复权限位，并会在安装时
   自动修复 autostart 目录权限。如已中招，安装本版后注销重新登录即可恢复。
5. 修复（2.9.68）：汇总区“本月支出/收入/结余”的数值在大字号下会压到该区边框
   （原高度写死 76px，13 号字仅余约 8px、15/17 号字直接溢出）。改为随字号
   自适应计算所需高度（标签+行距+数值+上下留白），各字号下数值与边框均
   留出约 14px 空隙。

八、本次更新（音乐）
本节含 2.9.69 ~ 2.9.74 的歌词相关修复。
1. 修复「打开音乐」按钮打不开播放器的问题：原启动方式（ll-cli run
   org.deepin.music）在本机失效，即使 deepin-music 已安装也打不开。改为优先
   启动 LX Music（gtk-launch lx-music-desktop），回退 /usr/bin/deepin-music，
   最后才用 ll-cli。LX Music 支持 MPRIS，启动后上一首/播放暂停/下一首即可接管。
2. 歌词强制显示为简体中文：原歌词直接透传，港台歌曲常显示繁体。现已内置繁→简
   映射（含臺→台、裡→里、為→为 等港台常用变体），在歌词解析处统一转换，不影响
   本地 .lrc 原文件。若仍有个别字未转，可在右键菜单「重新抓取歌词」后刷新。
3. 「停止」按钮语义修正（2.9.70）：2.9.69 中点击「关闭」会直接关闭挂件窗口、
   后台音乐继续播放，不符合预期。现改为「停止」按钮——点击只停止后台音乐播放，
   挂件窗口保持打开不退出；若想真正退出挂件，请使用右键菜单「退出」。
4. 歌词同步修正（2.9.71）：原卡拉OK歌词比播放器（如 LX Music）慢约半句——歌词行
   切换只在每 500 毫秒的轮询里更新，最多延迟半行。现改为每 100 毫秒跟随播放进度
   切换当前行、并把进度轮询收紧到 250 毫秒。
5. 歌词慢半句的根本修正（2.9.72）：2.9.71 只降低了轮询延迟，未解决真正的滞后来源。
   两个原因一并修掉——
   (a) 播放器经 MPRIS 上报的 Position 普遍滞后于其自身音频时钟（deepin-music /
       lx-music 都有约 0.5~2 秒上报延迟）。现为歌词判定内置 1000 毫秒固有提前量
       （LYR_LEAD_MS），叠加在右键菜单「歌词提前/延后」的微调量之上。
   (b) 进度外推的基准时刻取在 D-Bus 读取之前，导致 pos_ms 少算同步调用的耗时，
       误差逐轮累积、歌词越跑越慢。现改为读取完成后才取时刻。
   若仍有少量偏差，用右键菜单「歌词提前 N 秒」按 ±0.5 秒微调即可。
6. 修正「歌词提前/延后」按钮方向反了（2.9.73）：歌词判定公式是
   pos = 播放进度 + 固有提前量 + 用户微调量，该值越大歌词越超前。但这两个按钮
   传的值与实际效果相反——点「提前 0.5 秒」反而让歌词更慢、点「延后」反而更早，
   所以怎么调都不对。现已纠正方向：提前传正值、延后传负值。
7. 新增更快的校准档位与偏移显示（2.9.73）：右键菜单增加「歌词提前 2 秒（快速
   校准）」和「歌词延后 2 秒」，便于一次拉到位；并新增只读项「当前微调: ±X.X
   秒」，方便确认当前偏了多少。微调范围由 ±5 秒放宽到 ±10 秒。
8. 内建提前量由 1 秒提高到 2 秒（2.9.73）：实测仍慢约 5 个字（约 1.5~2.5 秒），
   1 秒补偿不足。
9. 清零被反向按钮污染的偏移量（2.9.73）：修正前点「提前」会持续累加负值，你本地
   的微调量已被点到 -5000 毫秒（-5 秒），它会抵消甚至反超内建提前量，导致装了
   新版仍慢。该存量值已重置为 0。若你手动调过，请以菜单里「当前微调」显示的
   数值为准重新校准。
10. 修复用 LX Music 时突然「未找到歌词」（2.9.74）：挂件原先只查 deepin-music 的
    歌词缓存目录，而 LX Music 的歌词存在它自己的 SQLite 库
    （~/.config/lx-music-desktop/LxDatas/lx.data.db 的 lyric 表，内容为 base64
    编码），挂件读不到，因此完全依赖网络抓取。lrclib.net 会返回 429 限流，一旦被限
    流就显示「未找到歌词」。现把 LX Music 本地库作为优先歌词源（本机实测 3/3 命中），
    网络只作兜底；同时剥离 LX Music lxlyric 的逐字时间标记 <起始毫秒,时长>，并按
    歌名+歌手精确匹配，避免取到别的歌的歌词。

十一、本次更新（视频 / 任务栏）
6. 桌面视频挂件小窗空闲态描边（2.9.72）：未播放时，桌面小窗四周显示一圈 1 像素
   细蓝色边框，标示可播放区域；一旦有片源播放或进入全屏即自动隐藏。
7. 全屏时隐藏任务栏（2.9.73 加强）：2.9.72 仅对主窗口和视频子窗口补发了 EWMH 全屏
   消息，deepin 窗口管理器未必据此收起任务栏。现改用 GTK 原生 `fullscreen()` 让 WM
   正确置位 `_NET_WM_STATE_FULLSCREEN`，并把主窗口与视频子窗口同时提到最前、铺满
   整个屏幕（含任务栏所占区域），双保险确保任务栏不再显示；退出全屏时一并还原。
8. 任务栏信息条默认位置（2.9.72）：默认水平偏移由 0 改为 60 像素，使信息条默认
   避开 dde-dock 最左侧的启动器/搜索图标，保持你当前看到的位置。已存在的用户
   配置不受影响；可用右键菜单「向左/向右微调 20 像素」随时调整。

十二、桌面挂件控制中心（2.9.75 重点更新）
1. 每个挂件新增「⚙ 设置」按钮，可分别配置：启动命令、附加参数、崩溃重启延迟、
   是否由守护自动重启、该挂件字体（留空=跟随系统默认字体）。设置保存在
   ~/.config/desktop-widgets/settings.json，重启该挂件后生效。
2. 新增系统托盘图标和右键菜单：打开控制中心 / 全部启动 / 全部停止 / 重启守护 /
   开机自启 / 检查更新 / 退出。关闭控制中心窗口只是隐藏到托盘，不会退出。
3. 标题栏与窗口右下角显示版本号；点「检查更新」会自动比对 GitHub 最新发行版，
   有新版本时顶部出现横幅，点「立即更新」即自动下载 .deb 并经管理员授权安装
   （Deepin 不可变系统会自动走 immutable 通道）。私有仓库第一次检查需要在
   右上角「⋮ → 更新设置」里填入 GitHub 访问令牌。
4. 滚动更顺手：滚轮滚动改为带缓动的平滑滚动，列表也可以用鼠标按住拖动；
   挂件状态刷新改为一次性扫描，界面不再一卡一顿。
5. 字体跟随更细：除跟随系统默认字体外，还能在单个挂件的设置里单独指定字体。
6. 启动器只显示「桌面挂件控制中心」一个图标：各挂件/任务栏工具的菜单项已加
   NoDisplay=true，统一由控制中心管理；开机自启不受影响。旧版机器可执行
   sudo bash hide-launcher-icons.sh 立即生效。
7. 修复桌面影视挂件（2.9.77）：之前全屏播放再退出后，控制窗会被降到置底层，
   被视频窗盖住，导致点不到按钮、右键菜单弹不出、电影关不掉。现已修复：
   退出全屏控制窗回到普通层；播放中右上角始终有个红色「✕」关闭钮；按 Esc
   可停止播放；控制中心里「停止」该挂件时 mpv 也会一起退出。另外修复了右键
   菜单开机自启项失效的问题，挂件文字改为跟随系统默认字体。
8. 换电脑安装不用愁（2.9.78 重点）：mpv 播放器和 tesseract OCR 引擎
   （含中文语言包）已经整个打进安装包，装在任何 Linux 电脑上都能直接
   播放电影、听收音机、截图识字，不需要再单独装 mpv，也不需要联网。
   安装包因此从 1.6MB 增大到约 61MB，装好占用约 200MB 磁盘。
9. 修复了一批隐藏问题（2.9.78）：天气/便签/日历/相框/RSS/音乐/计时器/影视
   共 9 个挂件的「开机自启」开关此前是坏的（生成的自启动文件名不对），
   现已修复；音乐/电台/相框/截图OCR/日历便签里硬编码的英文字体共 21 处，
   已全部改为跟随系统默认字体。

十三、依赖与配置
安装器会通过 apt 自动安装 Python、GTK、Pango、Xlib 和中文字体等依赖。挂件的个人配置保存在用户目录，重新安装不会主动删除已有配置。若安装后没有自动启动，请注销并重新登录。

十四、注意事项
本包是合集包，不是单独的收音机安装包。安装后可能替换同名的旧版桌面挂件和任务栏工具。
